## Known gap found by this run

The retry test for GH-008 passes, but it exposes that the in-memory installation insert and audit append are separate writes. If the audit write fails, the tenant row is kept and the retry sees `already_exists`. The PostgreSQL adapter must write the tenant row, installation row and audit event in one transaction.
